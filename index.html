Method, scope and limits

Post evaluation. 600 fictional posts: 144 authored contrast posts and 456 generated background items. Of 72 queries, 32 answerable test queries from 16 held-out event families determine retrieval scores; another 16 test queries have no answer. The 24 development queries determine each model's optional cutoff. Labels lack independent native-speaker review. One Uzbek query has ambiguous wording. This is not a production acceptance dataset.

English reference. The compact subset uses released SciFact relevance labels and the BEIR format. It retains positive documents, adds each query's top-five BM25 candidates, and fills by frozen hash order. The same texts, splits and labels were retained for all models. No training, test-driven prompt changes, or label edits occurred. Training-data overlap is unknown.

Retrieval. Models use their full embedding dimensions and published prompts, with normalized cosine scores over every document. Both E5 models split long documents into overlapping chunks and take the best query-to-chunk score. Other models encode complete inputs. Jina uses its retrieval adapter. Inputs were checked for complete coverage; no silent truncation was allowed. The GGUF runs reserved 2,048 tokens because all actual inputs fit; maximum context length was not benchmarked.

Execution and timing. Apple M3, 16 GiB unified memory. Each model ran separately. Smaller models used FP32 PyTorch MPS; Qwen 4B/8B used Q4_K_M with llama.cpp Metal. This compares local configurations at different precision, not the full-precision models under identical conditions. Native batch sizes were 8/4/2/1 by length. GGUF sent one input per HTTP request with default prefix caching. Encode times exclude loading and warmup; native times include each model.encode call, while GGUF includes HTTP calls and excludes tokenizer-parity preflight. Earlier measurements were reused from the same Mac. Downloads and preparation overlapped some early runs. Timings are single local observations, not a controlled speed distribution. No CPU/GPU utilization sampling was performed.

Verification. The eight additional models passed audits of 976 query rankings and 38 independent re-encoding probes. Earlier candidate runs passed 610 ranking checks. Audits checked source/data hashes, dimensions, normalization, input coverage, independent float64 score reconstruction and sklearn nDCG. Model names link to the pinned source checkpoints.

Skipped. Harrier 27B, Nemotron 8B and KaLM 12B were excluded at the user's request. No benchmark results are claimed for them.
